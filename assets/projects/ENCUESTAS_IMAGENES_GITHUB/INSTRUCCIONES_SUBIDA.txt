- MANIFIESTO.json: archivos, módulos, tamaños, dimensiones y SHA-256

PASOS
1. Extrae COMPLETO ENCUESTAS_IMAGENES_GITHUB.zip desde el Explorador de Windows.
2. Entra a la carpeta ENCUESTAS_IMAGENES_GITHUB extraída.
3. Abre PowerShell desde esa carpeta: clic derecho / Abrir en Terminal.
4. Ejecuta:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\SUBIR_ENCUESTAS_WINDOWS.ps1"
5. El script comprueba Git for Windows, los hashes SHA-256, el repositorio,
   su rama main, y el estado local antes de copiar solamente estas diez imágenes.
6. Si aún no tienes el repositorio local, lo clona en Documents/jeremyvg21.github.io.
   Para utilizar una copia ya descargada en otra ubicación, ejecuta:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\SUBIR_ENCUESTAS_WINDOWS.ps1" -RepoPath "C:\ruta\a\jeremyvg21.github.io"
7. Git solicitará autenticación si tu equipo todavía no ha iniciado sesión.
8. Comprueba los 10 archivos en GitHub y, tras la ejecución de GitHub Pages,
   abre la página del proyecto; su galería ya usa los mismos nombres de archivo.

IMPORTANTE
- Los PNG se copiaron byte a byte: no están recortados ni editados.
- No se altera ningún proyecto ajeno a Encuestas e Inscripciones.
- El script NO ejecuta push --force y se detiene ante cambios locales no guardados.
- Si Git falla, no supongas que se publicó: revisa el mensaje y corrige el problema.
- Solo publica estas imágenes DEMO autorizadas; no incluyas contraseñas ni datos reales.
- El código privado de la aplicación NO está incluido.
