Sistema de encuestas e inscripciones

Sistema administrativo para centralizar inscripciones familiares, comprobantes, revisión de pagos, asistencia y reportes, desarrollado con una arquitectura MVC propia en PHP.

PHP 8MVC propioPDOMySQLBootstrap 5Chart.jsPhpSpreadsheetDompdf

Necesidad empresarial

La gestión de inscripciones requiere formularios verificables, consulta de estados y evidencias de participación para evitar registros dispersos y facilitar el seguimiento.

Solución y arquitectura

Desarrollé una arquitectura MVC propia: punto de entrada, router, middleware, controladores, modelos, vistas, sesiones y servicios. La solución reúne el registro público de familias con herramientas administrativas para revisar comprobantes, actualizar estados, controlar asistencia y consultar reportes. El formulario del evento y la gestión de encuestas tienen alcances distintos: las encuestas nuevas permiten organizar datos generales, mientras su motor público genérico sigue pendiente.

Módulos y funcionalidades

Formularios e inscripciones

Formulario público con bloques dinámicos, validación en servidor, registro familiar y seguimiento de estados.

Administración

Autenticación, consulta, edición y búsqueda de participantes.

Control y seguridad

Consultas preparadas, tokens CSRF, prevención de doble envío y registros de actividad.

Reportes

Indicadores en Chart.js y exportaciones CSV, Excel y PDF.

Mi participación en el desarrollo

Desarrollé la arquitectura modular de esta solución, incluyendo router y patrón MVC propio, gestión de datos con PDO/MySQL, validaciones, herramientas de seguimiento y exportación. Documenté los flujos, las dependencias de datos y el alcance real de cada módulo. El caso de estudio utiliza información técnica y no muestra datos reales de participantes.

Este caso de estudio comparte información técnica de alcance público. No divulga código privado, credenciales, registros personales ni capturas pendientes de evaluación.

Del registro familiar al seguimiento administrativo

Arquitectura PHP propia

Diseñé el flujo index.php → router → middleware → controlador → servicios y modelos → PDO/MySQL → vistas. El autoload del código propio está separado de Composer, que resuelve Dompdf y PhpSpreadsheet. Esta separación permite mantener las reglas de negocio fuera de las plantillas.

Datos y consistencia

El motor heredado representa una inscripción familiar mediante una respuesta y detalles JSON para apoderados, estudiantes, invitados y comprobantes. Las transacciones protegen el guardado y un contador anual con bloqueo de fila reserva códigos. La asistencia añade configuración por encuesta y registros por participante.

Flujo público y validación

La familia completa los bloques del formulario, revisa el importe y adjunta de uno a tres comprobantes. El servidor valida los campos, recalcula las tarifas y comprueba el MIME del archivo antes de persistir. La confirmación utiliza redirección después del envío.

Encuestas y operación administrativa

El panel permite crear, editar, seleccionar y duplicar datos generales de encuestas. Para el evento heredado integra consulta y edición de inscripciones, historial de estados, verificación de pagos y asistencia individual o grupal de participantes habilitados.

Reportes y configuración

El centro de reportes reúne indicadores, siete gráficos declarados en Chart.js, filtros y resumen ejecutivo, con salidas CSV, Excel y PDF. SettingsService centraliza nueve secciones de configuración: identidad, evento, costos, pagos, banner, encuesta, correos, seguridad y apariencia.

Controles y revisión técnica

Implementé autenticación administrativa, sesiones, consultas preparadas, CSRF y almacenamiento privado de comprobantes. La auditoría local identifica también límites pendientes, como la protección de la confirmación pública y la limitación de intentos de acceso; no presenta estos mecanismos como una garantía de seguridad integral.

Infraestructura reproducible

El sistema se desarrolló originalmente para hosting compartido. La reapertura local utiliza Laragon con PHP 8.3.30, Apache 2.4.66 y MySQL 8.4.3, una base DEMO compatible y datos ficticios. El esquema local no se presenta como copia de la base original de Hostinger.

Mantenimiento y evidencia

Se comprobaron por HTTP autenticación, encuestas, inscripción con archivo permitido, rechazo de archivo inválido, estados, asistencia y exportaciones. La revisión corrigió una incompatibilidad de longitud de título, una advertencia de registro y el tratamiento de texto como fórmula en Excel. Las capturas DEMO seleccionadas cuentan con una galería preparada; la verificación visual de las rutas públicas exige cargar primero sus archivos PNG.

Competencias demostradas: diseño de arquitectura PHP, modelado relacional, transacciones, validación de negocio, tratamiento de archivos, integración de librerías, pruebas funcionales y documentación. El motor público genérico para nuevas encuestas, las notificaciones y la edición pública posterior no se presentan como funciones terminadas.
